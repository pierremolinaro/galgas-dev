\tableDesMatieresLocaleDeProfondeurRelative{1}


Le type \ggsq+@bool+ est le type booléen. Les deux mots réservés \ggsq+true+ et \ggsq+false+ sont du type \ggsq+@bool+ type, et dénote les valeurs \emph{vari} et \emph{faux}. Le seul constructeur du \ggsq+@bool+ type est le constructeur \ggsq!default!, qui initialise un booléen à \ggsq+false+.


\section{Conversion en chaîne de caractères}

\subsectionGetter{cString}{bool}

\begin{galgas4box}
getter cString -> @string
\end{galgas4box}

Retourne la chaîne \ggsq!"true"! si le booléen est vrai, et la chaîne \ggsq!"false"! dans le cas contraire.







\subsectionGetter{ocString}{bool}

\begin{galgas4box}
getter ocString -> @string
\end{galgas4box}

Retourne la chaîne \ggsq!"YES"! si le booléen est vrai, et la chaîne \ggsq!"NO"! dans le cas contraire.

\section{Opérateurs logiques}

\begin{galgas4box}
operator @bool & @bool -> @bool
operator @bool | @bool -> @bool
operator @bool ^ @bool -> @bool
operator not @bool -> @bool
\end{galgas4box}

Le type \ggsq+@bool+ accepte les trois opérateurs suivants
\begin{itemize}
\item l'opérateur \ggsq!&! infixé qui effectue un \emph{et logique} ;
\item l'opérateur \ggsq!|! infixé qui effectue un \emph{ou logique} ;
\item l'opérateur \ggsq!^! infixé qui effectue un \emph{ou exclusif logique} ;
\item l'opérateur \ggsq!not! infixe qui effectue la\emph{négation logique}.
\end{itemize}








\section{Comparaison}

Le type \ggsq!@bool! implémente les six opérateurs de comparaison \ggsq!==!, \ggsq+!=+, \ggsq!<!, \ggsq!<=!, \ggsq!>! et \ggsq!>=!, avec \ggsq!false < true!.
