The \ggsq+@double+ object values correspond to the C type \ggsq+@double+ values. You can initialize an \ggsq+@double+ object from a float constant:

\begin{galgas4}
@double myDouble = 123.456
\end{galgas4}

Note that a \ggsq+@double+ constant is characterized by the occurrence of the decimal point (.)

\section{Arithmétique}

\subsection{Opérateurs infixés}

Le type \ggsq+@double+ accepte les opérateurs arithmétiques infixés suivants :
\begin{itemize}
  \item \ggsq!+!, addition ;
  \item \ggsq!-!, soustraction ;
  \item \ggsq!*!, multiplication ;
  \item \ggsq!/!, division, une erreur d'exécution est déclenchée si le diviseur est nul ;
  \item \ggsq!mod!, calcul du reste, une erreur d'exécution est déclenchée si le diviseur est nul ;
  \item \ggsq!&/!, division, qui retourne zéro si le diviseur est nul.
\end{itemize}

Ces opérateurs exigent que les deux opérandes soient des objets du même type \ggsq+@double+.

\subsection{Opérateurs préfixés}
Le type \ggsq+@double+ accepte les opérateurs arithmétiques préfixés suivants :
\begin{itemize}
  \item \ggsq!+!, qui retourne simplement la valeur de l'opérande ;
  \item \ggsq!-!, négation arithmétique.
\end{itemize}

La valeur renvoyée est du même type  \ggsq+@double+.


\subsectionLabel{Instructions}{affectationsCombineesDouble}

Le type \ggsq+@double+ accepte les instructions arithmétiques suivantes :
\begin{itemize}
  \item \ggsq!+=!, addition ;
  \item \ggsq!-=!, soustraction ;
  \item \ggsq!*=!, multiplication ;
  \item \ggsq!/=!, division.
\end{itemize}

\ggsq!x+=y! est équivalent à \ggsq!x=x+y! ; \ggsq!x-=y! est équivalent à \ggsq!x=x-y!.
La variable cible \ggsq!x!, comme l'expression source \ggsq!y! doivent être du même type \ggsq+@double+.







\section{Comparison Operators}

The \ggsq+@double+ type supports the six comparison operators:\newline

\begin{tabular}{|c|c|}
\hline
$=$ & Equality \\
\hline
$!=$ & Non Equality \\
\hline
$<$  & Strict Lower Than \\
\hline
$<=$  & Lower or Equal \\
\hline
$>$  & Strict Greater Than \\
\hline
$>=$  & Greater or Equal \\
\hline
\end{tabular}

Theses operators require both arguments to be \ggsq+@double+ objects, and return a \ggsq+@bool+ object.
