\chapitreTypePredefiniLabelIndex{uint64}

\tableDesMatieresLocaleDeProfondeurRelative{1}

An \ggsq+@u64+ object value is a 64-bit unsigned integer value. You can initialize an \ggsq+@u64+ object from a 64-bit unsigned integer constant:

\begin{galgas4}
@u64 myUnsignedInteger = 123_456L
\end{galgas4}

Note the \texttt{L} suffix is required for a 64-bit unsigned integer constant.

\section{Constructeurs}




\subsectionConstructor{max}{uint64}

\begin{galgas4}
constructor max -> @u64
\end{galgas4}

Returns an \ggsq+@u64+ object that the maximum value of the 64-bit unsigned range ($2^{64}-1$).


\subsectionConstructor{uint64BaseValueWithCompressedBitString}{uint64}

\begin{galgas4}
constructor uint64BaseValueWithCompressedBitString
   ?@string inBitString
   -> @u64
\end{galgas4}


Returns an \ggsq+@u64+ object computed from a string containing '0', '1' or 'X' characters, replacing all occurrences of 'X' by '0'.

The inBitString argument should contain only '0', '1' or 'X' characters. A run time exception is raised if an other character appears.

This constructor considers the \emph{inBitString} argument value as a binary encoding of an integer value. First, it internally replaces all 'X's by '0's, and then converts the resulting string into an integer value that is the one returned by this constructor.

Note that the first character of the \emph{inBitString} argument value corresponds to the most significant bit of the converted value.


\textbf{Exemple :}
\begin{galgas4}
@u64 v [uint64BaseValueWithCompressedBitString !"01XX10"]
log v # Displays <@u64:18>
\end{galgas4}





\subsectionConstructor{uint64MaskWithCompressedBitString}{uint64}

\begin{galgas4}
constructor uint64MaskWithCompressedBitString ?@string inBitString -> @u64
\end{galgas4}


Returns an \ggsq+@u64+ object computed from a string containing '0', '1' or 'X' characters, replacing all occurrences of '0' by '1' and all occurrences of 'X' by '0'.

The \emph{inBitString} argument should contain only '0', '1' and 'X' characters. A run time exception is raised if an other character appears.

This constructor considers the \emph{inBitString} argument value as a binary encoding of an integer value. First, it internally replaces all '0's by '1's and all 'X's by '0's, and then converts the resulting string into an integer value that is the one returned by this constructor.

Note that the first '0' or '1' character of the \emph{inBitString} argument value corresponds to the most significant Bit of the converted value.

\textbf{Exemple :}
\begin{galgas4}
@u64 v [uint64MaskWithCompressedBitString !"01XX10"] ;
log v ; # Displays <@u64:51> ;
\end{galgas4}



\subsectionConstructor{uint64WithBitString}{uint64}

\begin{galgas4}
constructor uint64WithBitString ?@string inBitString -> @u64
\end{galgas4}


Returns an \ggsq+@u64+ object computed from a string containing '0' or '1' characters.

The \emph{inBitString} argument should contain only '0' and '1' characters. A run time exception is raised if an other character appears.

This constructor considers the \emph{inBitString} argument value as a binary encoding of an integer value. It returns an \ggsq+@u64+ object containing the converted value.

Note that the first '1' character of the \emph{inBitString} argument value corresponds to the most significant bit of the converted value.

\textbf{Exemple :}
\begin{galgas4}
@u64 v [uint64WithBitString !"0101"]] ;
log v ; # Displays <@u64:5> ;
\end{galgas4}


\section{Getters}


\subsectionGetter{alphaString}{uint64}

Ce \emph{getter} permet de convertir un \ggsq!@u64! en une chaîne de caractères, telle que l'ordre des entiers est conservé sur la chaîne obtenue.

La chaîne obtenue comporte exactement 14 lettres minuscules. C'est en fait une conversion en base 26, la lettre \ggsq=a= ayant la valeur $0$, et la lettre \ggsq=z= la valeur $25$.


\begin{galgas4}
  message [0L alphaString] + "\n"          # aaaaaaaaaaaaaa
  message [12_345L alphaString] + "\n"     # aaaaaaaaaaasgv
  message [@u64.max alphaString] + "\n" # hlhxczmxsyumqp
\end{galgas4}

\subsectionGetter{bigint}{uint64}

Ce \emph{getter} permet de convertir un \ggsq!@u64! en \ggsq!@bigint!. Comme la plage des valeurs des \ggsq!bigint! n'est limitée que par la mémoire disponible, il n'échoue jamais.

\begin{galgas4}
  message [[1234L bigint] string] + "\n" # 1234
\end{galgas4}


\subsectionGetter{double}{uint64}

\begin{galgas4}
getter double -> @double
\end{galgas4}

Returns the receiver's value converted in a \ggsq+@double+ object. As a 64-bit integer value can always be converted in a \ggsq+@double+ value, this getter never fails.



\subsectionGetter{hexString}{uint64}


\begin{galgas4}
getter hexString -> @string
\end{galgas4}

Returns the an hexadecimal string representation of the receiver value, prefixed by the string \texttt{0x}. For getting an hexadecimal representation string with any prefix, see \refGetterPage{uint64}{xString}.






\subsectionGetter{hexStringSeparatedBy}{uint64}

\begin{galgas4}
getter hexStringSeparatedBy ?@char inSeparator ?@u32 inGroup -> @string
\end{galgas4}

Returns the an hexadecimal string representation of the receiver value, prefixed by the string \texttt{0x}. Groups of \ggsq=inGroup= digits are separated by the \ggsq=inSeparator= character.

If \ggsq=inGroup= is equal to zero, a run-time error is raised.

For example:
\begin{galgas4}
let s = [0x123456789ABCDEF0L hexStringSeparatedBy !'_' !4] # 0x1234_5678_9ABC_DEF0
\end{galgas4}





\subsectionGetter{sint}{uint64}

\begin{galgas4}
getter sint -> @s32
\end{galgas4}

Returns the receiver's value in an \refTypePredefini{sint} (32-bit signed integer) object. An error is raised is receiver's value is greater than $2^{31}-1$. This getter is the only way to convert an \refTypePredefini{uint64} object into an \refTypePredefini{sint} object.



\subsectionGetter{sint64}{uint64}

\begin{galgas4}
getter sint64 -> @s64
\end{galgas4}

Returns the receiver's value in an \refTypePredefini{sint64} (64-bit signed integer) object. An error is raised is receiver's value is greater than $2^{63}-1$. This getter is the only way to convert an \refTypePredefini{uint64} object into an \refTypePredefini{sint64} object.


\subsectionGetter{string}{uint64}

\begin{galgas4}
getter string -> @string
\end{galgas4}

Returns a decimal string representation of the receiver's value. For an hexadecimal string representation of the receiver's value, see \refGetterPage{uint64}{hexString} and \refGetterPage{uint64}{xString}.



\subsectionGetter{uint}{uint64}

\begin{galgas4}
getter uint -> @u32
\end{galgas4}

Returns the receiver's value in an \refTypePredefini{uint} (32-bit unsigned integer) object. An error is raised is receiver's value is greater than $2^{32}-1$. This getter is the only way to convert an \refTypePredefini{uint64} object into an \refTypePredefini{uint} object.


\subsectionGetter{uintSlice}{uint64}

\begin{galgas4}
getter uintSlice ?@u32 inStartBit ?@u32 inBitCount -> @u32
\end{galgas4}



Returns an \refTypePredefini{uint} value, extracted from a bit slice of the receiver's value. The receiver's value is right shifted by \emph{inStartBit}, and the resulted value is and'ed with a mask equal to $2^{inBitCount}-1$.


\textbf{Exemple :}
\begin{galgas4}
@u64 v = 0x1234_5678_9ABC_DEF0L
@u32 result = [v uintSlice !4 !5] # The result value is 0x8_9ABC
\end{galgas4}

\section{Arithmétique}

\subsection{Opérateurs infixés}

Le type \ggsq+@u64+ accepte les opérateurs arithmétiques infixés suivants :
\begin{itemize}
  \item \ggsq!+!, addition, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!-!, soustraction, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!*!, multiplication, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!/!, division, une erreur d'exécution est déclenchée si le diviseur est nul ;
  \item \ggsq!mod!, calcul du reste, une erreur d'exécution est déclenchée si le diviseur est nul ;
  \item \ggsq!&+!, addition, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&-!, soustraction, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&*!, multiplication, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&/!, division, qui retourne zéro si le diviseur est nul.
\end{itemize}

Ces opérateurs exigent que les deux opérandes soient des objets du même type \ggsq+@u64+.

\subsection{Opérateur préfixé}
Le type \ggsq+@u64+ accepte un opérateur arithmétique préfixé :
\begin{itemize}
  \item \ggsq!+!, qui retourne simplement la valeur de l'opérande.
\end{itemize}

\subsectionLabel{Instructions}{instructionsUINT64}

Le type \ggsq+@u64+ accepte les instructions arithmétiques suivantes :
\begin{itemize}
  \item \ggsq!+=!, addition, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!-=!, soustraction, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!*=!, multiplication, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!/=!, division, une erreur d'exécution est déclenchée en cas division par zéro ;
  \item \ggsq!++!, incrémentation, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!--!, décrémentation, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!&++!, incrémentation, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&--!, décrémentation, le résultat étant silencieusement tronqué sur 64 bits.
\end{itemize}

\ggsq!x+=y! est équivalent à \ggsq!x=x+y! ; \ggsq!x-=y! est équivalent à \ggsq!x=x-y!.
La variable cible \ggsq!x!, comme l'expression source \ggsq!y! doivent être du même type \ggsq+@u64+.

Incrémentation et décrémentation sont des instructions, et ne peuvent pas apparaître des expressions.
\begin{galgas4}
@u64 n = ... ; n ++ # Incrémentation
\end{galgas4}

\begin{galgas4}
@u64 n = ... ; n -- # Décrémentation
\end{galgas4}


\section{Shift Operators}


The \ggsq+@u32+ type supports right and left shift operators:\newline

\begin{tabular}{|c|c|}
\hline
$<<$ & Left shift \\
\hline
$>>$ & Right shift \\
\hline
\end{tabular}

Theses operators require the left argument to be \ggsq+@u64+ object, and  the right argument to be \ggsq+@u32+ object.\newline

Note the right shift inserts always a zero bit in the most significant bit location (it is a logical right shift).\newline

The actual amount of the shift is the value of the right-hand operand masked by 63, i.e. the shift distance is always between 0 and 63.




\section{Logical Operators}

The \ggsq+@u64+ type supports the three bit-wise logical diadic operators:

\begin{tabular}{|c|c|}
\hline
$\&$ & Bit-wise and \\
\hline
\textbar & Bit-wise or \\
\hline
\^\  & Bit-wise exclusive or \\
\hline
\end{tabular}

Theses operators require both arguments to be \ggsq+@u64+ objects.\newline


The \ggsq+@u64+ type supports the bit-wise logical unary operator:

\begin{tabular}{|c|c|}
  \hline
  $\sim$ & Bit-wise complementation \\
  \hline
\end{tabular}

This operator returns an \ggsq+@u64+ object.




\section{Comparison Operators}

The \ggsq+@u64+ type supports the six comparison operators:

\begin{tabular}{|c|c|}
\hline
$=$ & Equality \\
\hline
$!=$ & Non Equality \\
\hline
$<$  & Strict Lower Than \\
\hline
$<=$  & Lower or Equal \\
\hline
$>$  & Strict Greater Than \\
\hline
$>=$  & Greater or Equal \\
\hline
\end{tabular}

Theses operators require both arguments to be \ggsq+@u64+ objects, and return a \ggsq+@bool+ object.
