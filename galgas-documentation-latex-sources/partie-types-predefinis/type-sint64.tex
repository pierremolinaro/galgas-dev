\chapitreTypePredefiniLabelIndex{sint64}

\tableDesMatieresLocaleDeProfondeurRelative{1}


An \ggsq+@s64+ object value is a 64-bit signed integer value. You can initialize an \ggsq+@s64+ object from an 64-bit signed integer constant:\\

\texttt{@s64 mySignedInteger = 123\_456LS ;}

Note that a 64-bit signed integer constant is characterized by the 'LS' suffix.

\section{Constructors}


\subsectionConstructor{min}{sint64}

\begin{galgas4}
constructor min -> @s64
\end{galgas4}

Returns an \ggsq+@s64+ object that the minimum value of the 64-bit signed range ($-2^{63}$).





\subsectionConstructor{max}{sint64}

\begin{galgas4}
constructor max -> @s64
\end{galgas4}

Returns an \ggsq+@s64+ object that the maximum value of the 64-bit signed range ($2^{63}-1$).


\section{Getters}


\subsectionGetter{bigint}{sint64}

Ce \emph{getter} permet de convertir un \ggsq!@s64! en \ggsq!@bigint!. Comme la plage des valeurs des \ggsq!bigint! n'est limitée que par la mémoire disponible, il n'échoue jamais.

\begin{galgas4}
  message [[-1234LS bigint] string] + "\n" # -1234
\end{galgas4}



\subsectionGetter{double}{sint64}

\begin{galgas4}
getter double -> @double
\end{galgas4}

Returns the receiver's value converted in a \ggsq+@double+ object. As a 64-bit integer value can always be converted in a \ggsq+@double+ value, this getter never fails.



\subsectionGetter{hexStringSeparatedBy}{sint64}

\begin{galgas4}
getter hexStringSeparatedBy ?@char inSeparator ?@u32 inGroup -> @string
\end{galgas4}

Returns the an hexadecimal string representation of the receiver value, prefixed by the string \texttt{0x}. Groups of \ggsq=inGroup= digits are separated by the \ggsq=inSeparator= character.

If \ggsq=inGroup= is equal to zero, a run-time error is raised.

For example:
\begin{galgas4}
let s = [0x123456789ABCDEF0LS hexStringSeparatedBy !'_' !3] # 0x1_234_567_89A_BCD_EF0
\end{galgas4}




\subsectionGetter{sint}{sint64}

\begin{galgas4}
getter sint -> @s32
\end{galgas4}

Returns the receiver's value in an \refTypePredefini{sint} (32-bit signed integer) object. An error is raised is receiver's value is lower than $-2^{31}$ or greater than $2^{31}-1$.

This getter is the only way to convert an \refTypePredefini{sint64} object into an \refTypePredefini{sint} object.





\subsectionGetter{string}{sint64}

\begin{galgas4}
getter string -> @string
\end{galgas4}

Returns a decimal string representation of the receiver's value. This getter never fails.








\subsectionGetter{uint}{sint64}

\begin{galgas4}
getter uint -> @u32
\end{galgas4}

Returns the receiver's value in an \refTypePredefini{uint} (32-bit unsigned integer) object. An error is raised is receiver's value is negative or greater than $2^{32}-1$.

This getter is the only way to convert an \refTypePredefini{sint64} object into an \refTypePredefini{uint} object.





\subsectionGetter{uint64}{sint64}

\begin{galgas4}
getter uint64 -> @u64
\end{galgas4}

Returns the receiver's value in an \refTypePredefini{uint64} (64-bit unsigned integer) object. This getter raises a run-time error if the receiver's value is negative.

This getter is the only way to convert an \refTypePredefini{sint64} object into an \refTypePredefini{uint64} object.








\section{Arithmétique}

\subsection{Opérateurs infixés}

Le type \ggsq+@s64+ accepte les opérateurs arithmétiques infixés suivants :
\begin{itemize}
  \item \ggsq!+!, addition, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!-!, soustraction, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!*!, multiplication, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!/!, division, une erreur d'exécution est déclenchée si le diviseur est nul ;
  \item \ggsq!mod!, calcul du reste, une erreur d'exécution est déclenchée si le diviseur est nul ;
  \item \ggsq!&+!, addition, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&-!, soustraction, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&*!, multiplication, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&/!, division, qui retourne zéro si le diviseur est nul.
\end{itemize}

Ces opérateurs exigent que les deux opérandes soient des objets du même type \ggsq+@s64+.

\subsection{Opérateurs préfixés}
Le type \ggsq+@s64+ accepte les opérateurs arithmétiques préfixés suivants :
\begin{itemize}
  \item \ggsq!+!, qui retourne simplement la valeur de l'opérande ;
  \item \ggsq!-!, négation arithmétique, une erreur d'exécution est déclenchée si l'opérande est égal à $-2^{63}$ ;
  \item \ggsq!&-!, négation arithmétique, sans détection de débordement : la négation de $-2^{63}$ est $-2^{63}$.
\end{itemize}

La valeur renvoyée est du même type  \ggsq+@s64+.


\subsectionLabel{Instructions}{instructionsSINT64}

Le type \ggsq+@s64+ accepte les instructions arithmétiques suivantes :
\begin{itemize}
  \item \ggsq!+=!, addition, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!-=!, soustraction, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!*=!, multiplication, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!/=!, division, une erreur d'exécution est déclenchée en cas division par zéro ;
  \item \ggsq!++!, incrémentation, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!--!, décrémentation, une erreur d'exécution est déclenchée en cas de débordement ;
  \item \ggsq!&++!, incrémentation, le résultat étant silencieusement tronqué sur 64 bits ;
  \item \ggsq!&--!, décrémentation, le résultat étant silencieusement tronqué sur 64 bits.
\end{itemize}

\ggsq!x+=y! est équivalent à \ggsq!x=x+y! ; \ggsq!x-=y! est équivalent à \ggsq!x=x-y!.
La variable cible \ggsq!x!, comme l'expression source \ggsq!y! doivent être du même type \ggsq+@s64+.

Incrémentation et décrémentation sont des instructions, et ne peuvent pas apparaître des expressions.
\begin{galgas4}
@s64 n = ... ; n ++ # Incrémentation
\end{galgas4}

\begin{galgas4}
@s64 n = ... ; n -- # Décrémentation
\end{galgas4}







\section{Shift Operators}


The \ggsq+@s64+ type supports right and left shift operators:\newline

\begin{tabular}{|c|c|}
\hline
$<<$ & Left shift \\
\hline
$>>$ & Right shift \\
\hline
\end{tabular}

Theses operators require the right argument to be \ggsq+@s64+ object, and the left argument to be \ggsq+@u32+ object.\newline

Note the right shift inserts a zero bit in the most significant bit location if the receiver's value is negative, and a one bit otherwise (it is a arithmetic right shift).\newline

The actual amount of the shift is the value of the right-hand operand masked by 63, i.e. the shift distance is always between 0 and 63.




\section{Logical Operators}

The \ggsq+@s64+ type supports the three bit-wise logical operators:\newline

\begin{tabular}{|c|c|}
\hline
$\&$ & Bit-wise and \\
\hline
\textbar & Bit-wise or \\
\hline
\^\  & Bit-wise exclusive or \\
\hline
\end{tabular}

Theses operators require both arguments to be \ggsq+@s64+ objects.\newline


The \ggsq+@s64+ type supports the bit-wise logical unary operator:\newline

\begin{tabular}{|c|c|}
\hline
$\sim$ & Bit-wise complementation \\
\hline
\end{tabular}

This operator returns an \ggsq+@s64+ object.







\section{Comparison Operators}

The \ggsq+@s64+ type supports the six comparison operators:\newline

\begin{tabular}{|c|c|}
\hline
$=$ & Equality \\
\hline
$!=$ & Non Equality \\
\hline
$<$  & Strict Lower Than \\
\hline
$<=$  & Lower or Equal \\
\hline
$>$  & Strict Greater Than \\
\hline
$>=$  & Greater or Equal \\
\hline
\end{tabular}

Theses operators require both arguments to be \ggsq+@s64+ objects, and return a \ggsq+@bool+ object.
