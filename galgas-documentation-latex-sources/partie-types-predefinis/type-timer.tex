\chapitreTypePredefiniLabelIndex{timer}

\tableDesMatieresLocaleDeProfondeurRelative{1}


Le type \ggsq!@timer! permet de mesurer des durées d'exécution de portions de code ; une utilisation typique est :

\begin{galgas4}
var @timer t = .start
  # instructions
message "Durée : " + [t string] + "\n" # Affiche la durée d'exécution des instructions
\end{galgas4}


\section{Constructeurs}

Le type \ggsq!@timer! accepte deux constructeurs :
\begin{itemize}
  \item le contructeur \ggsq!start! ;
\end{itemize}


\subsectionConstructor{start}{timer}

\begin{galgas4box}
constructor @timer start -> @timer
\end{galgas4box}

Appeler le constructeur \ggsq!start! est la seule façon d'instancier un objet \ggsq!@timer!. Le chronomètre est enclenché, c'est-à-dire qu'il compte la durée à partir de laquelle le constructeur \ggsq!start! a été appelé.







\section{Setters}

Le type \ggsq!@timer! accepte deux \emph{setters} :
\begin{itemize}
  \item le \emph{setter} \ggsq!resume! ;
  \item le \emph{setter} \ggsq!stop!.
\end{itemize}

\subsectionSetter{resume}{timer}

\begin{galgas4box}
setter @timer resume
\end{galgas4box}

Le \emph{setter} \ggsq!resume! redémarre le chronomètre si il est arrêté, et le réinitialise si il est en marche.
\subsectionSetter{stop}{timer}

\begin{galgas4box}
setter @timer stop
\end{galgas4box}

Le \emph{setter} \ggsq!stop! arrête le chronomètre. Si il est déjà arrêté, appeler ce \emph{setter} n'a aucun effet.







\section{Getters}

Le type \ggsq!@timer! accepte trois \emph{getters} :
\begin{itemize}
  \item le \emph{getter} \ggsq!isRunning! ;
  \item le \emph{getter} \ggsq!msFromStart! ;
  \item le \emph{getter} \ggsq!string!.
\end{itemize}

\subsectionGetter{isRunning}{timer}

\begin{galgas4box}
getter @timer isRunning -> @bool
\end{galgas4box}

Ce \emph{getter} renvoie  \ggsq!true! si le récepteur décompte le temps, ou \ggsq!false! si il a été arrêté par un appel au \emph{setter} \ggsq!stop!.


\subsectionGetter{msFromStart}{timer}

\begin{galgas4box}
getter @timer msFromStart -> @u32
\end{galgas4box}

La valeur obtenue par le \emph{getter} \ggsq!msFromStart! est la durée écoulée depuis son instanciation (par le constructeur \ggsq!start!) ou depuis le dernier appel au \emph{setter} \ggsq!resume!. La durée est exprimée en millisecondes.


\subsectionGetter{string}{timer}

\begin{galgas4box}
getter @timer string -> @string
\end{galgas4box}

La valeur obtenue par le \emph{getter} \ggsq!string! est la durée écoulée depuis son instanciation (par le constructeur \ggsq!start!) ou depuis le dernier appel au \emph{setter} \ggsq!resume!. La durée est exprimée sous la forme d'une chaîne de caractères.
