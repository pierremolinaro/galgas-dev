\section{Déclaration d'un type de liste}

La déclaration d'un type \ggsq+list+ nomme toutes les propriétés des éléments de la liste~:

\begin{galgas4}
list @MyList {
  @string mFirstAttribute
  @bool mSecondAttribute
}
\end{galgas4}

\section{Constructeurs}

\subsection{Le constructeur \texttt{emptyList}}

Pour chaque liste, le constructeur \ggsq+emptyList+ est implicitement déclaré. Il retourne une liste vide~:

\begin{galgas4}
@MyList aList = [@MyList emptyList]
\end{galgas4}


\subsection{Le constructeur \texttt{listWithValue}}

Ce constructeur permet de construire directement une liste contenant un élément~:

\begin{galgas4}
@MyList aList = [@myList listWithValue !"c" !3]
\end{galgas4}


Using this constructor is equivalent to:

\begin{galgas4}
@MyList aList = [@MyList emptyList]
aList += !"c" !3
\end{galgas4}

\section{Adding elements}

\subsectionLabel{The \texttt{+=} operator}{operatorPlusEgalSurListe}

The  \ggsq*+=* operator adds a new element at the end of the list. The right side expressions should correspond to the attributes declared in the \ggsq+list+ declaration:\\

\begin{galgas4}
@MyList aList = ...
@string aString = ...
@bool aBool = ...
aList += !aString !aBool
\end{galgas4}


\subsection{L'instruction \texttt{+=}}

L'instruction \ggsq*cible += expression* concatène la liste définie par la valeur de \ggsq+expression+ à la liste \ggsq+cible+ :

\begin{galgas4}
@MyList aList = ...
@MyList secondList = ...
aList += secondList
\end{galgas4}







\subsection{Le setter \texttt{append}}

Le setter \texttt{append} permet d'ajouter un élément à la fin de la liste, à partir d'un objet du type \emph{élément de la liste} implicitement déclaré.


\begin{galgas4}
@MyList aList = ...
@string aString = ...
@bool aBool = ...
@MyList-element élément = .new {!aString !aBool}
[!?aList append !élément]
\end{galgas4}


\subsection{The \texttt{prependValue} setter}

{\bf \textcolor{red}{Ce setter a été supprimé~; utiliser le setter \emph{insertAtIndex}.}}

The \ggsq+prependValue+ setter adds a new element at the begining of the list. The right side expressions should correspond to the attributes declared in the  \ggsq+list+ declaration:

\begin{galgas4}
@MyList aList = ...
@string aString = ...
@bool aBool = ...
[!?aList prependValue !aString !aBool]
\end{galgas4}




\subsection{Setter \texttt{insertAtIndex}}

Le setter \ggsq+insertAtIndex+ permet d'insérer un nouvel élément à une position quelconque de la liste. Si le type \ggsq+list+ correspondant déclare $n$ champs, l'appel du setter comprend $n+1$ arguments :
\begin{itemize}
  \item les $n$ premiers correspondent aux valeurs des champs du nouvel élément inséré~;
  \item le dernier est l'indice d'insertion, une valeur de type \ggsq+@uint+.
\end{itemize}

L'indice d'insertion peut varier entre $0$ (insertion au début, comme le faisait le setter \emph{prependValue}), et la longueur courante de la liste (insertion à la fin, comme le fait l'opérateur \ggsq*+=*, \refSubsectionPage{operatorPlusEgalSurListe}). Si la liste est vide, insérer à l'indice $0$ est donc la seule possibilité.

Par exemple :

\begin{galgas4}
@MyList aList = ...
@string aString = ...
@bool aBool = ..
[!?aList insertAtIndex !aString !aBool !0]
\end{galgas4}

\subsection{The concatenation operator}

The «~\ggsq*+*~» operator can be used for concatenating two lists of the same type:


\begin{galgas4}
@MyList firstList = ..
@MyList secondList = ..
@MyList thirdList = firstList + secondList
\end{galgas4}

\section{Removing elements}

\subsection{Setter \texttt{popFirst}}


The \ggsq+popFirst+ setter removes and returns the first element of the list. The right side expressions should correspond to the attributes declared in the \ggsq+list+ declaration:

\begin{galgas4}
@MyList aList = ...
@string aString
@bool aBool
[!?aList popFirst ?aString ?aBool]
\end{galgas4}

If the list is empty when \ggsq+popFirst+ setter is invoked, a run-time error is raised and the input arguments are not valuated.

\subsection{Setter \texttt{popLast}}


The \ggsq+popLast+ setter removes and returns the last element of the list. The right side expressions should correspond to the attributes declared in the \ggsq+list+ declaration:

\begin{galgas4}
@MyList aList = ...
@string aString
@bool aBool
[!?aList popLast ?aString ?aBool]
\end{galgas4}

If the list is empty when \ggsq+popLast+ is invoked, a run-time error is raised and the input arguments are not valuated.

\section{Methods}

\subsection{The \texttt{first} method}

The \ggsq+first+ method returns the first element of the list. The element is not removed. The right side expressions should correspond to the attributes declared in the \ggsq+list+ declaration:

\begin{galgas4}
@MyList aList = ...
@string aString
@bool aBool
[aList first ?aString ?aBool]
\end{galgas4}

If the list is empty when \ggsq+first+ is invoked, a run-time error is raised and the input arguments are not valuated.

\subsection{The \texttt{last} method}

The \ggsq+last+ method returns the last element of the list. The element is not removed. The right side expressions should correspond to the attributes declared in the \ggsq+list+ declaration:\\

\begin{galgas4}
@MyList aList = ...
@string aString
@bool aBool
[aList last ?aString ?aBool]
\end{galgas4}


If the list is empty when \ggsq+last+ is invoked, a run-time error is raised and the input arguments are not valuated.








\section{Getters}

\subsection{Le getter \texttt{count}}

\begin{galgas4}
getter count -> @uint
\end{galgas4}

Le \emph{getter} \ggsq+count+ retourne le nombre d'éléments du récepteur.



\subsection{Le getter \texttt{length}}

\begin{galgas4}
getter length -> @uint
\end{galgas4}

Le \emph{getter} \ggsq+length+ retourne le nombre d'éléments du récepteur. Obsolète : utiliser \ggsq+count+.


\subsection{Le getter \texttt{range}}

\begin{galgas4}
getter range -> @range
\end{galgas4}

The \ggsq+range+ getter returns a range starting at $0$ of length equal to the number of elements of the receiver.




\subsection{Le getter \texttt{subListFromIndex}}

\begin{galgas4}
getter subListFromIndex ?@uint inIndex -> @self
\end{galgas4}

This getter returns a new list containing the elements of the receiver from the one at a given index to the end. The  \ggsq+inIndex+ value should be lower or equal to the length of the receiver's value. If \ggsq+inIndex+ is equal to the length of the receiver, the getter returns an empty list.






\subsection{Le getter \texttt{subListToIndex}}

\begin{galgas4}
getter subListToIndex ?@uint inIndex -> @self
\end{galgas4}

Ce \emph{getter} retourne une liste comprenant les éléments du récepteur à partir de l'indice $0$ jusqu'à l'indice \ggsq+inIndex+ compris. Si \ggsq+inIndex+ est supérieur ou égal au nombre d'éléments de la liste, une erreur d'exécution est déclenchée.




\subsection{Le getter \texttt{subListWithRange}}

\begin{galgas4}
getter subListWithRange
  ?@range inRange
  -> @self
\end{galgas4}

This getter returns a list containing the elements of the receiver that lie within a given range. The range must not exceed the length of the receiver's value, that is $range\_start + range\_length \leqslant list\_length$. If the range's length is equal to zero, this getter returns an empty list.















\section{Enumerating a list with a \texttt{for} instruction}

The \ggsq+for+ instruction can be used for enumerating list objects. By default, lists are enumerated in the insertion order; enumeration in the reverse order is performed using the \ggsq+>+ qualifier.

There are two ways for accessing element values:
\begin{itemize}
\item using the implicitly declared constants that receive the current attribute values;
\item declare explicitly constants that receive the current attribute values.
\end{itemize}

Given the list declaration:

\begin{galgas4}
list @MyList {
  @string mFirstAttribute
  @bool mSecondAttribute
}
\end{galgas4}

\subsection{Enumeration using the implicitly declared constants}

For every attribute, a constant of the same name is available in the \ggsq+do+ instruction list. Theses constants receive the value of the corresponding attribute of the current element.

\begin{galgas4}
for () in aList do
  # the mFirstAttribute constant receives the value
  # of the mFirstAttribute attribute of the current element,
  # and the mSecondAttribute constant receives the value
  # of the mSecondAttribute attribute of the current element.
end
\end{galgas4}

\subsection{Enumeration using the explicitly declared constants}

The \ggsq+for+ header declares a sequence of constants, corresponding to the attribute list of the \ggsq+do+ declaration. Theses constants receive the value of the corresponding attribute of the current element.


\begin{galgas4}
for (kString kBool) in aList do
  # the kString constant receives the value
  # of the mFirstAttribute attribute of the current element,
  # and the kBool constant receives the value
  # of the mSecondAttribute attribute of the current element.
end
\end{galgas4}

\subsection{Enumeration in the reverse order}

In GALGAS 1.7.3 and later, you can enumerate a list in the reverse order using the \ggsq+>+ qualifier:

\begin{galgas4}
for > (kString kBool) in aList do
  ...
end
\end{galgas4}




\section{Direct Access of an element attribute}

In GALGAS 1.7.5 and later, lists can be used as an array. Each element of a list is associated with an \ggsq+@uint+ index, spanning from 0 to element count (value returned by \ggsq+length+ getter) minus one.

The element retrieved with \ggsq+first+ method is at index 0.

The element retrieved with \ggsq+last+ method is at index equal to element count minus one.

\subsection{Read Access}

By default and for every attribute, a getter is provided to retrieve the value of this attribute for an element at a given index. For example, for an attribute named \emph{name}, the \emph{nameAtIndex} getter is provided. It accepts one \ggsq+@uint+ argument, the value of the index.

Si la propriété a été déclarée \ggsq+private+, seules les \emph{méthodes}, \emph{getters} et \emph{setters} de cette classe peuvent accéder cette propriété.



\subsection{Write Access}

By default, a setter is provided for performing a direct write access to an attribute at a given index.

The setter name is the name of the attribute with the first letter capitalized, prefixed by \emph{set} and suffixed by \emph{AtIndex}: for an attribute named \emph{name}, the setter is named \emph{setNameAtIndex}. It accepts two arguments, the first one is the new attribute's value, the second one an \ggsq+@uint+ argument, the value of the index.

For example:

\begin{galgas4}
list @MyList {
  @string mFirstAttribute
  @bool mSecondAttribute
}
...
@string s = ...
[!?aList setMFirstAttributeAtIndex !s !1]
\end{galgas4}

Si la propriété a été déclarée \ggsq+private+, seules les \emph{méthodes}, \emph{getters} et \emph{setters} de cette classe peuvent accéder cette propriété.


\subsection{Example of read and write accesses}

\begin{galgas4}
list @myList {
  @string name
}
...
@myList strList [emptyList]
strList += !"a"
strList += !"b"
strList += !"c"
strList += !"d"
@string s = [strList nameAtIndex !0]
log s # displays LOGGING s: <@string:"a">
s = [strList nameAtIndex !1]
log s # displays LOGGING s: <@string:"b">
s = [strList nameAtIndex !2]
log s # displays LOGGING s: <@string:"c">
s = [strList nameAtIndex !3]
log s # displays LOGGING s: <@string:"d">
[!?strList setNameAtIndex !"x" !0]
[!?strList setNameAtIndex !"y" !1]
[!?strList setNameAtIndex !"z" !2]
[!?strList setNameAtIndex !"t" !3]
s = [strList nameAtIndex !0]
log s # displays LOGGING s: <@string:"x">
s = [strList nameAtIndex !1]
log s # displays LOGGING s: <@string:"y">
s = [strList nameAtIndex !2]
log s # displays LOGGING s: <@string:"z">
s = [strList nameAtIndex !3]
log s # displays LOGGING s: <@string:"t">
\end{galgas4}
