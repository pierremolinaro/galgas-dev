\chapterLabel{Le type \texttt{dict}}{typeDict}
%-------------------------------------------------------------

\tableDesMatieresLocaleDeProfondeurRelative{1}


Un objet de type \ggsq+dict+ est un dictionnaire. Contrairement à un objet de type \ggsq+map+ , le type de la clé est déclaré explicitement et peut être d'un type quelconque.

{\bf\color{red} Attention ! } Le type de la clé d'un dictionnaire peut être un \ggsq+@lstring+, comme la clé implicite d'une \ggsq+map+. Toutefois, la sémantique est différente. Dans une \ggsq=map=, c'est la composante \ggsq=string= de la clé qui est prise en compte comme clé effective. La composante \ggsq=location= n'est utilisée que pour le signalement d'erreur. Dans un \ggsq=dict=, le type déclaré comme clé est intégralement pris en compte : si la clé d'un \ggsq=dict= est un \ggsq=@lstring=, la comparaison des clés prend en compte la composante \ggsq=string= {\bf et} la composante \ggsq=location=.

\section{Déclaration}

\begin{galgas4}
dict @MonDictionnaire : @u32 {
  @string mPremier
  @bool mSecond
}
\end{galgas4}

La déclaration d'un type \ggsq+dict+ nomme~:
\begin{itemize}
  \item le nom du type \ggsq+dict+ (ici \ggsq+@MonDictionnaire+)~;
  \item le type de la clé (ici \ggsq+@u32+)~;
  \item les propriétés associées (ici \ggsq=mPremier= et \ggsq=mSecond=).
\end{itemize}

Les noms \ggsq=key=, \ggsq=object= et \ggsq=desciption= sont interdits pour une propriété.

On peut déclarer un dictionaire sans propriété, et ainsi gérer des \emph{ensembles} :

\begin{galgas4}
dict @autreDictionnaire : @u32 { }
\end{galgas4}





\section{Constructeurs}

Pour initialiser un dictionnaire vide, il y a trois possibilités, sémantiquement identiques~:
\begin{itemize}
  \item la constante \texttt{\{\}} (\refSubsectionPage{constanteDictVide})~;
  \item le constructeur \texttt{emptyDict} (\refSubsectionPage{constructeurEmptyDict})~;
  \item le constructeur \texttt{default} (\refSubsectionPage{constructeurDictDefault}).
\end{itemize}


\subsectionLabel{Constante \texttt{\{\}}}{constanteDictVide}

Cette constante permet d'instancier un dictionnaire vide. Exemple~:
\begin{galgas4}
@MonDictionnaire unDictionnaire = {}
\end{galgas4}

Ou encore~:

\begin{galgas4}
var unDictionnaire = @MonDictionnaire {}
\end{galgas4}

\subsectionLabel{Constructeur \texttt{emptyDict}}{constructeurEmptyDict}

Pour instancier un dictionnaire vide, une autre possibilité est d'appeler le constructeur \ggsq=emptyDict=. Exemple~:
\begin{galgas4}
@MonDictionnaire unDictionnaire = .emptyDict
\end{galgas4}

Ou encore~:

\begin{galgas4}
var unDictionnaire = @MonDictionnaire.emptyDict
\end{galgas4}



\subsectionLabel{Constructeur \texttt{default}}{constructeurDictDefault}


Un dictionnaire accepte le constructeur \ggsq=default=. Exemple~:
\begin{galgas4}
@MonDictionnaire unDictionnaire = .default
\end{galgas4}

Ou encore~:

\begin{galgas4}
var unDictionnaire = @MonDictionnaire.default
\end{galgas4}






\section{Insertion}

Un \ggsq+dict+ implémente implicitement l'opérateur \ggsq:+=: qui permet d'insérer une nouvelle entrée à un dictionnaire. Ses arguments sont, dans l'ordre~: un objet du type de la clé, puis un objet par propriété déclarée. Aucune erreur n'est déclenchée en cas de tentative d'insertion d'une clé déjà existante~; les valeurs des propriétés associées à la clé sont simplement remplacées.

Par exemple~:
\begin{galgas4}
@MonDictionnaire unDictionnaire = {}
@u32 clef = ...
@string s = ...
@u32 v = ...
unDictionnaire += !clef !s !v
\end{galgas4}











\section{Recherche}

Une \ggsq+dict+ déclare implicitement la \emph{méthode} de recherche \ggsq=searchKey= qui permet de rechercher une entrée d'un dictionnaire, et retourne la valeur de ses propriétés associées. Une erreur est déclenchée si la clé n'existe pas.

La \emph{méthode} de recherche \ggsq=searchKey= est appelée dans une \emph{instruction d'appel de méthode}~:
\begin{itemize}
  \item le premier argument (sortie) est une expression de type de la clé qui caractérise la clé à rechercher~;
  \item ensuite, pour chaque propriété déclarée, un argument en entrée nommant une variable destinée à recevoir la valeur de la propriété correspondante.
\end{itemize}


Par exemple~:
\begin{galgas4}
@MonDictionnaire unDictionnaire = {}
...
@lstring clef = ...
[unDictionnaire searchKey !clef ?@string s ?@u32 v]
\end{galgas4}








\section{Retrait}

Un \ggsq+dict+ déclare implicitement le \emph{setter} de retrait \ggsq=removeKey=. Il permet de retirer une entrée d'un dictionnaire, et retourne la valeur des propriétés associées à la clé retirée. Une erreur est déclenchée si la clé n'existe pas.



Le \emph{setter} de retrait \ggsq=removeKey= est appelé dans une \emph{instruction d'appel de setter}~:
\begin{itemize}
  \item le premier argument (sortie) est une expression de type de la clé qui caractérise la clé à retirer~;
  \item ensuite, pour chaque propriété déclarée, un argument en entrée nommant une variable destinée à recevoir la valeur de la propriété correspondant de la clé retirée.
\end{itemize}

Par exemple~:
\begin{galgas4}
@MonDictionnaire unDictionnaire = {}
...
@lstring clef = ...
[!?unDictionnaire removeKey !clef ?@string s ?@u32 v]
\end{galgas4}

\subsection{Getter \texttt{count}}

\begin{galgas4}
getter count -> @u32
\end{galgas4}


Le \emph{getter} \ggsq+count+ retourne un \ggsq+@u32+ qui contient le nombre d'entrées du dictionnaire.



\subsection{Getter \texttt{hasKey}}


Le \emph{getter} \ggsq+hasKey+ retourne un \ggsq+@bool+ qui est \ggsq+true+ si la clé \ggsq+inKey+ est dans le dictionnaire, \ggsq+false+ dans le cas contraire.
