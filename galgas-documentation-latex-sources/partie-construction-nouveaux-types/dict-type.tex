\section{Déclaration d'un type dictionaire}

Un type dictionaire dont les clés sont de type \ggsq+@KEY+ et les éléments sont type \ggsq+@VALUE+ est implicitement déclaré par la construction \ggsq+[@KEY : @VALUE]+. Le type \ggsq+@KEY+ doit être \emph{comparable} et le \ggsq+@VALUE+ est un type quelconque.






\section{Initialiseur}

\begin{galgas4}
init [@KEY : @VALUE] ()
\end{galgas4}

L'initialiseur sans argument crée un dictionaire vide.


\section{Fonctions}

\subsection{Fonction \texttt{count}}

\begin{galgas4}
func [@KEY : @VALUE].count () -> @u32
\end{galgas4}


Retourne un \ggsq+@u32+ qui contient le nombre d'entrées du dictionnaire.



\subsection{Fonction \texttt{contains}}

\begin{galgas4}
func [@KEY : @VALUE].contains (@KEY inKey) -> @bool
\end{galgas4}

Retourne un \ggsq+@bool+ qui est \ggsq+true+ si la clé \ggsq+inKey+ est dans le dictionnaire, \ggsq+false+ dans le cas contraire.









\section{Méthodes mutantes}



\subsection{Méthode mutante \texttt{remove}}

\begin{galgas4}
mutating func [@KEY : @VALUE].remove (@KEY inKey)
\end{galgas4}

Retire la clé \ggsq+inKey+ du dictionnaire. Une erreur est déclenchée si la clé est absente du dictionnaire.





\section{Opérateurs d'indexation}

\subsection{Lecture}

\begin{galgas4box}
func [@KEY : @VALUE] [@KEY inKey] -> @VALUE?
\end{galgas4box}

Retourne la valeur associée à la clé \ggsq*inKey*, ou \ggsq*nil* si la clé est absente.


\subsection{Lecture, avec valeur par défaut}

\begin{galgas4box}
func [@KEY : @VALUE] [@KEY inKey, ?default: @VALUE inDefaultValue] -> @VALUE
\end{galgas4box}

Retourne la valeur associée à la clé \ggsq*inKey*, ou la valeur de \ggsq*inDefaultValue* si la clé est absente.



\subsection{Lecture, erreur si clé absente}

\begin{galgas4box}
func [@KEY : @VALUE] [?unwrap: @KEY inKey] -> @VALUE
\end{galgas4box}

Retourne la valeur associée à la clé \ggsq*inKey*, ou déclenche une erreur si la clé est absente.




\subsection{Écriture}

\begin{galgas4box}
mutating func [@KEY : @VALUE] [@KEY inKey] = @VALUE inValue
\end{galgas4box}

Associe la valeur \ggsq*inValue* à la clé \ggsq*inKey*. Si la clé est déjà présente, l'ancienne valeur est perdue.






\section{Énumération}

L'instruction \ggsq+for+ permet d'énumérer un dictionaire. L'énumération s'effectue dans l'ordre croissant des clés.


\begin{galgas4}
var [@string : @u32] dictionaire = @()
dictionaire ["a"] = 1
dictionaire ["b"] = 2
dictionaire ["c"] = 3
for (clé, valeur) in dictionaire do
  print (clé)
  print (" --> ")
  println (valeur) // a --> 1, b --> 2, c --> 3
end
\end{galgas4}
